# ECECS Academic English

将 ECECS Pro 的本科英文写作要求整理为可复用的 Codex skill：约 IELTS 6.5–7.5 的语言复杂度，学术、自然、清楚，润色时保留原意与证据力度。

这是用户项目要求的整理，不是学校官方标准、IELTS评分工具或AI检测规避工具。核心要求与补充写作约定见 [来源及示例](references/basis-and-examples.md)。

## 使用

将本仓库克隆为 `~/.codex/skills/ececs-academic-english`（已有目录时先核对，勿覆盖）。在能发现本地skills的新会话中调用：

```text
请使用 $ececs-academic-english 润色以下本科报告段落，只做必要微调，保留原意、数据、引文和不确定性；用中文说明关键改动。
```

支持局部润色、语言审阅及修改解释。实际作业的语言、引用和AI使用规则优先。仓库仅包含skill说明、界面元数据和来源说明，不包含私人课程报告或原始课件。
